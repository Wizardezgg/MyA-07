# Bazar Dor

A daily commodity and grocery price tracking web application for Bangladesh. Built with Next.js 15, TypeScript, Tailwind CSS, and BetterAuth.

## Features
- **Live Price Ticker**: Real-time ticker showing price changes and percentages.
- **Top Movers**: Dedicated sections for daily price rises and price drops.
- **Category Browsing & Sorting**: 7 commodity categories with price sorting (Low to High, High to Low).
- **Market Comparison**: Product page showing lowest, highest, and average prices across different markets.
- **Authentication**: Email sign in and social login (Google & GitHub) powered by BetterAuth.
- **User Profile**: Update profile name and manage account details.

## Tech Stack
- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- BetterAuth
- React Hot Toast

## Setup
1. Clone the repo: `git clone https://github.com/Wizardezgg/MyA-07.git`
2. Install packages: `npm install`
3. Add environment variables in `.env.local`
4. Run locally: `npm run dev`
